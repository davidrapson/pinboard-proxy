# Pinboard Proxy

A proxy server for [Pinboard](https://pinboard.in/) to return public tagged items for a given account.

## Getting Started

Install dependencies:

``` sh
npm install
```

You'll need an environment variable with your [API token](https://pinboard.in/api#authentication):

``` sh
export PINBOARD_API_TOKEN="MYAPIOKEN"
```

Start the server:

``` sh
npm start
```
